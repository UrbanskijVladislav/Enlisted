# 🎖️ Enlisted - Тактичний Інформаційний Хаб та База Знань

Сучасний, швидкий та інтерактивний веб-портал, присвячений грі **Enlisted**, створений українською мовою з темним мілітарі-дизайном, ефектами неоморфізму та плавною анімацією.

---

## 🚀 Як відкрити та запустити сайт

1. **Пряме відкриття у браузері**:
   - Просто відкрийте файл [index.html](file:///c:/Users/USER/Desktop/Enlisted/index.html) у будь-якому сучасному браузері (Chrome, Edge, Firefox, Safari, Brave).
   - Жодних збірок або встановлення додаткових бібліотек не потрібно!

2. **Або через локальний веб-сервер**:
   ```bash
   # Якщо у вас встановлений Python:
   python -m http.server 8000

   # Або через npx:
   npx serve .
   ```
   Після цього перейдіть за адресою `http://localhost:8000`.

## 🛠️ Реалізований функціонал

1. **Головний екран (Hero)**:
   - Епічний заголовок, швидкі посилання та лічильники ключової статистики гри (4 нації, BR I-V, 50+ зразків зброї, 10 класів бійців).
2. **Фракції та Театри бойових дій**:
   - Огляд 4 націй: СРСР, США/Британія, Німеччина, Японія.
   - Їхні історичні особливості, переваги, слабкості, кампанії та коронна зброя.
3. **Система Бойових Рейтингів (BR I - V)**:
   - Інтерактивні картки для кожного рангу з поясненням черги матчмейкінгу та захисту новачків від топ-техніки.
4. **База озброєння та техніки (Арсенал)**:
   - Живий пошук за назвою та характеристиками.
   - Фільтри за нацією, категорією (гвинтівки, ПП, кулемети, штурмові, танки, літаки) та рівнем BR.
   - Інтерактивні картки з графіками урону та скорострільності.
   - Детальне тактичне модальне вікно для кожного екземпляра.
5. **Інтерактивний Білдер Загону (Squad Builder)**:
   - Вибір нації загону.
   - Призначення бійців (Командир, Інженер, Кулеметник, Бронебійник, Стрілець).
   - Вибір зброї та додаткового спорядження для кожного бійця.
   - **Автоматичний розрахунок максимального BR загону** з попередженням про баланс боїв.
   - Збереження у `localStorage` та можливість копіювання сетапу в буфер обміну.
6. **Інтерактивне Порівняння Зброї (Weapon Comparison)**:
   - Порівняння будь-яких двох одиниць озброєння віч-на-віч.
   - Візуальні динамічні індикатори переваги за параметрами (урон, скорострільність, магазин, дальність, перезарядка).
7. **Польовий статут (Гайди)**:
   - Посібник із золотого правила Інженера та точок відродження (Rally Points).
   - Правила підбору та розподілу BR.
   - Ефективне керування ботами (клавіша X, формації).
   - Тактика боротьби з танками (вибухові пакети під днище, Молотов).
   - Повний огляд усіх 10 класів піхоти.
8. **Архіви фронту (Медіа-галерея)**:
   - Скріншоти та кадри боїв із лайтбокс-переглядом у повній якості.
9. **Стрічка новин та Системні вимоги**:
   - Останні оновлення, сезонні події та технічні вимоги для ПК.
